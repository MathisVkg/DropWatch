# Addon-owned icons

LootTracker.tga: original 64×64 circular teal package mark. Settings.tga: original 32×32 eight-tooth gear. Both are uncompressed 32-bit BGRA TGA, top-left origin, with 8-bit alpha and power-of-two dimensions. Geometry was generated from circles, line segments and radial gear teeth with 4× supersampling. No external artwork/library is required. Native sizing uses 30-pixel minimap, 16-pixel title and 14-pixel gear presentations.
